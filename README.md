# SheeShanKhout
Burmese Rock Paper Scissors

A simple browser-based game inspired by the traditional Burmese hand game **Shee Shan Khout**, similar to *Rock–Paper–Scissors*.  
Built with **HTML**, **CSS**, and **JavaScript** to demonstrate DOM manipulation, event handling, and persistent state management using **localStorage**.

## 🎮 Features
- **Interactive gameplay:** Choose between *Hlan*, *Dar*, or *Kat Kyee* using buttons or keyboard keys (`1`, `2`, `3`).
- **Auto Play mode:** Simulates random moves automatically using `setInterval`.
- **Persistent scoring:** Win/loss/tie counts are saved locally in the browser.
- **Keyboard controls:** Supports quick input and shortcuts for reset and auto-play.
- **Clean and responsive UI:** Styled with CSS for simplicity and readability.

## 🧠 What I Learned
- DOM manipulation and event listeners in JavaScript  
- Managing state and persistence with `localStorage`  
- Building interactive front-end applications with modular code  
- Basic UI design and feedback loops for user interaction

- CSS3  
- Vanilla JavaScript (ES6)
